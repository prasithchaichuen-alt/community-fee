# ระบบจัดการชุมชนเอื้ออาทรริมกก

ระบบจัดการข้อมูลชุมชนสำหรับเก็บเงินค่าบำรุงรักษาและจัดการรายจ่ายของชุมชนเอื้ออาทรริมกก

## ฟีเจอร์หลัก

### 📊 ระบบจัดการรายรับ
- บันทึกการชำระเงินค่าบำรุงรักษา
- แสดงประวัติการชำระเงิน
- ออกรายงานรายวัน/เดือน/ปี
- กรองข้อมูลตามประเภทการชำระเงิน (เงินสด/โอน)

### 💸 ระบบจัดการรายจ่าย
- บันทึกและจัดการรายการรายจ่าย
- แยกหมวดหมู่รายจ่าย (ส่วนกลาง/บริการ/กิจกรรม/ดำเนินการ)
- ค้นหาและกรองรายจ่าย
- ออกรายงานสรุปรายจ่าย

### 🔧 ระบบจัดการ (Admin)
- จัดการข้อมูลสมาชิก
- ตั้งค่าปุ่มแสดง/ซ่อน
- สำรองฐานข้อมูล
- จัดการรายการรายจ่าย

## การติดตั้งและรัน

### ข้อกำหนดเบื้องต้น
- Python 3.8+
- SQLite3

### การติดตั้ง
```bash
# Clone โปรเจค
git clone <repository-url>
cd community_debug

# ติดตั้ง dependencies
pip install -r requirements.txt

# รันแอปพลิเคชัน
python app.py
```

### เข้าถึงระบบ
- หน้าแรก: http://localhost:5000
- หน้า Admin: http://localhost:5000/admin

## โครงสร้างโปรเจค

```
community_debug/
├── app.py                 # ไฟล์หลัก Flask
├── community.db          # ฐานข้อมูล SQLite
├── requirements.txt      # รายการไลบรารี
├── README.md            # คำอธิบายโปรเจค
└── templates/           # เทมเพลต HTML
    ├── index.html
    ├── admin.html
    ├── expense.html
    ├── payment.html
    ├── history.html
    ├── manage_expenses.html
    ├── report_print.html
    └── report_expense_print.html
```

## เทคโนโลยีที่ใช้

- **Backend**: Python Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **JavaScript**: Vanilla JS สำหรับ AJAX

## การใช้งาน

1. **หน้าแรก**: บันทึกการชำระเงินและรายจ่าย
2. **หน้า Admin**: จัดการข้อมูลและออกรายงาน
3. **ระบบรายงาน**: ออกรายงาน PDF สำหรับพิมพ์
