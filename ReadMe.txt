ติดตั้งตัวสร้าง venv (ถ้าเครื่องยังไม่มี)
บางครั้ง Ubuntu ตัวเริ่มต้นอาจจะยังไม่ได้แถมตัว venv มาให้ ให้รันคำสั่งนี้เพื่อติดตั้งครับ:

Bash
sudo apt update
sudo apt install python3-venv -y

สร้าง Virtual Environment
สร้างโฟลเดอร์สภาพแวดล้อมจำลองขึ้นมา (นิยมตั้งชื่อว่า venv เหมือนกัน):

Bash
python3 -m venv venv

เกร็ดเล็ก ๆ สำหรับการทำงานต่อจากนี้:
ทุกครั้งที่ปิดคอมแล้วจะกลับมาทำงาน: คุณต้อง cd เข้ามาที่โฟลเดอร์นี้แล้วพิมพ์ 

source venv/bin/activate 

ก่อนเสมอ เพื่อปลุก Python ตัวนี้ขึ้นมา
ถ้าอยากเลิกใช้: แค่พิมพ์ deactivate หรือปิด Terminal ไปได้เลย
-----------------------------------------------------------
ปิดชั่วคราว:

sudo systemctl stop myapp

แค่นี้โปรแกรมก็หยุดแล้ว เอาไปแก้ไฟล์ได้เลย

ถ้าแก้เสร็จแล้วจะเปิดกลับ:

sudo systemctl start myapp

ถ้าอยากเช็กว่ายังรันอยู่ไหม:

sudo systemctl status myapp

จบตรงนี้ได้เลย ไม่ต้องไปยุ่งอย่างอื่น 👍
